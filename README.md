# Mage.space Automated Login with Hostinger Catch-All & IMAP

ഈ പ്രോജക്റ്റ് ഉപയോഗിച്ച് **Mage.space**-ലേക്ക് റാൻഡം ഇമെയിലുകൾ ഉപയോഗിച്ച് തനിയെ (Automated) ലോഗിൻ ചെയ്യാനും ലോഗിൻ ലിങ്ക് സ്വയം സ്വീകരിച്ച് സെഷൻ സേവ് ചെയ്യാനും സാധിക്കും.

---

## 📌 ഘട്ടം 1: Hostinger-ൽ "Catch-All" ഓൺ ചെയ്യുക (One-time Setup)

1. നിങ്ങളുടെ **Hostinger hPanel** ലോഗിൻ ചെയ്യുക.
2. **Emails** സെക്ഷനിലേക്ക് പോയി നിങ്ങളുടെ ഡൊമെയ്ൻ തെരഞ്ഞെടുക്കുക.
3. ഇടത് വശത്തെ മെനുവിൽ **Catch-All Email** (അല്ലെങ്കിൽ Email Settings -> Catch-all) കാണാം.
4. **Catch-All** എന്നത് **Enable / Active** ആക്കുക.
5. "Forward to" അല്ലെങ്കിൽ "Deliver to" എന്നതിൽ നിങ്ങളുടെ പ്രധാന ഇമെയിൽ അഡ്രസ്സ് തെരഞ്ഞെടുക്കുക (ഉദാ: `admin@yourdomain.com`).
6. **Save** ചെയ്യുക.

*(ഇതോടെ നിങ്ങളുടെ ഡൊമെയ്‌നിലെ ഏത് റാൻഡം ഇമെയിലിലേക്ക് വരുന്ന മെയിലും നിങ്ങളുടെ പ്രധാന ഇൻബോക്സിലേക്ക് എത്തും).*

---

## 📌 ഘട്ടം 2: `.env` ഫയൽ ക്രമീകരിക്കുക

ഫോൾഡറിലുള്ള [`.env`](file:///c:/Users/Azhar/Desktop/web%20automation/.env) ഫയൽ തുറന്ന് നിങ്ങളുടെ വിവരങ്ങൾ നൽകുക:

```env
HOSTINGER_IMAP_HOST=imap.hostinger.com
HOSTINGER_IMAP_PORT=993

# നിങ്ങളുടെ പ്രധാന Hostinger ഇമെയിലും പാസ്‌വേർഡും:
HOSTINGER_EMAIL=admin@yourdomain.com
HOSTINGER_PASSWORD=your_password_here

# നിങ്ങളുടെ ഡൊമെയ്ൻ:
DOMAIN=yourdomain.com

# ബ്രൗസർ സ്ക്രീനിൽ കാണണോ? (false = കാണാം, true = ബാക്ക്ഗ്രൗണ്ട്)
HEADLESS=false
```

## 📌 ഘട്ടം 3: IMAP കണക്ഷൻ ടെസ്റ്റ് ചെയ്യുക

നിങ്ങൾ നൽകിയ ഇമെയിലും പാസ്‌വേർഡും ശരിയാണോ എന്ന് പരിശോധിക്കാൻ ടെർമിനലിൽ താഴെ പറയുന്ന കമാൻഡ് റൺ ചെയ്യുക:

```bash
npm run test-imap
```

`[SUCCESS] Hostinger IMAP-ലേക്ക് വിജയകരമായി കണക്ട് ചെയ്തു!` എന്ന് കാണിച്ചാൽ ക്രഡൻഷ്യലുകൾ കൃത്യമാണ്.

---

## 📌 ഘട്ടം 4: ഓട്ടോമേഷൻ റൺ ചെയ്യുക

ഓട്ടോമാറ്റിക് ലോഗിൻ പ്രോസസ്സ് തുടങ്ങാൻ താഴെ പറയുന്ന കമാൻഡ് നൽകുക:

```bash
npm start
```

### സ്ക്രിപ്റ്റ് സ്വയം ചെയ്യുന്ന കാര്യങ്ങൾ:
1. പുതിയൊരു റാൻഡം ഇമെയിൽ ഉണ്ടാക്കുന്നു (ഉദാ: `mage_x89a1b@yourdomain.com`).
2. ബ്രൗസർ തുറന്ന് Mage.space-ൽ ഇമെയിൽ ടൈപ്പ് ചെയ്ത് ലിങ്ക് അയക്കുന്നു.
3. Hostinger ഇൻബോക്സിൽ നിന്ന് ലോഗിൻ ലിങ്ക് സ്വയം കണ്ടെത്തുന്നു.
4. അതേ ബ്രൗസർ ടാബിൽ ലിങ്ക് തുറന്ന് ലോഗിൻ പൂർത്തിയാക്കുന്നു.
5. ഭാവി ആവശ്യങ്ങൾക്കായി ലോഗിൻ സെഷൻ/കുക്കികൾ `./sessions/` ഫോൾഡറിലേക്ക് സേവ് ചെയ്യുന്നു.
